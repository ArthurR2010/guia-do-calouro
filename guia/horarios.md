# Horários

Horários da turma do primeiro ano do Ensino Médio
do Colégio Batista Mineiro — Unidade Betim.

## Segunda a sexta-feira: manhã

| Atividade | Horário |
|---|---|
| Início das aulas | 07:00 |
| Intervalo | 09:30 às 09:50 |
| Término das aulas | 12:20 |

## Terça-feira: tarde

| Atividade | Horário |
|---|---|
| Almoço | 12:20 às 13:00 |
| Início das aulas | 13:00 |
| Intervalo | 15:30 às 15:50 |
| Término das aulas | 18:20 |

## Quinta-feira: provas

Após as aulas da manhã, há intervalo para almoço.

| Atividade | Horário |
|---|---|
| Retorno à escola | Até 13:20 |
| Início das provas | 13:30 |
| Encerramento das provas | Até 16:30 |

Alterações são comunicadas pelo Batista ID.
